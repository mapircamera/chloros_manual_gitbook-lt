# Pradžia

<div data-full-width="false"><figure><img src=".gitbook/assets/chloros_logo_transparent.png" alt=""><figcaption></figcaption></figure></div>Chloros yra [MAPIR](https://www.mapir.camera) sukurta programinė įranga, skirta vaizdų ir kitų jutiklių duomenų apdorojimui.

***{% hint style="success" %}**Kas naujo Chloros 1.1.0 versijoje**: natūralus Linux palaikymas (amd64 ir arm64), NVIDIA Jetson krašto kompiuterija, dinaminis skaičiavimo pritaikymas, 4-siūlų apdorojimo vamzdynas, naujos CLI komandos ir parinktys. Visą pakeitimų sąrašą rasite [Atsisiųsti](download.md).
{% endhint %}

Chloros yra prieinamas 3 programos režimais:

## Chloros: Darbalaukio GUI programa

Atskiras langas su visomis funkcijomis. _Tik „Windows“._

## [Chloros CLI: Komandinės eilutės sąsaja](CLI.md)

Komandinės eilutės paketinis apdorojimas. Puikiai tinka automatizavimui, scenarijų kūrimui ir darbui be grafinės sąsajos. Galima naudoti **Windows, Linux amd64 ir Linux arm64 (NVIDIA Jetson)**. _Norint naudotis CLI, reikalinga Chloros+ licencija._

## [Chloros API: Python SDK](api-python-sdk.md)

Programinė Python sąsaja, skirta automatizavimui ir individualiems darbo srautams. Puikiai tinka tyrimų procesams, integracijai su esamomis Python programomis ir individualių įrankių kūrimui. Prieinama **visose platformose** per `pip install chloros-sdk`. _API prieigai reikalinga Chloros+ licencija._***

## Palaikomos platformos

| Platforma | GUI | CLI | Python SDK |
| --- | --- | --- | --- |
| **Windows 10/11** | Taip | Taip | Taip |
| **Linux amd64 (x86_64)** | Ne | Taip | Taip |
| **Linux arm64 (NVIDIA Jetson)** | Ne | Taip | Taip |

Linux diegimo instrukcijas rasite skyriuje [Linux ir kraštų kompiuterija](linux/linux-overview.md).

***

## Chloros+

Nors Chloros daugeliui užduočių yra nemokamas, galbūt jums prireiks daugiau. Tuomet jums gali būti naudinga mokama Chloros+ licencija. Turėdami Chloros+ licenciją, galėsite naudotis tokiomis naujomis funkcijomis kaip:

* **Daugiagijis apdorojimas**: žymiai pagreitinkite vaizdų apdorojimą didesniuose projektuose, vienu metu apdorodami vaizdus per apdorojimo grandinę.
* **GPU (CUDA) pagreitinimas**: pasinaudokite šiuolaikinėmis didesnės talpos GPU atminties galimybėmis, kad dar labiau pagreitintumėte vaizdų apdorojimo procesą. Geriausiems rezultatams pasiekti rekomenduojame 4 GB ar daugiau VRAM.
* **Chloros+**[**CLI**](CLI.md)**Prieiga**: paleiskite Chloros+ iš komandinės eilutės, kad automatizuotumėte ir integruotumėte į savo programinę įrangą.
* **Chloros+**[**API**](api-python-sdk.md)**Prieiga:** paleiskite Chloros+ iš Python programiniam valdymui, leidžiančiam sklandžiai integruoti į jūsų tyrimų procesus, duomenų analizės darbo eigą ir pritaikytas programas.
* **Naudojimas keliuose įrenginiuose**: kiekviena Chloros+ licencija leidžia registruoti 2 ar daugiau įrenginių. Naudokite savo MAPIR Cloud paskyrą registruotiems įrenginiams valdyti. Pridėkite palaikymą daugiau įrenginių, atnaujinę savo Chloros+ licenciją.
* **Išplėstinis tekstūrą atpažįstantis debayerio metodas:** aukštos kokybės kraštus atpažįstantis debayeris, suderintas su AI/ML triukšmo šalinimo modeliu, kuris pašalina beveik visą debayerio triukšmą. 
* **Pasirinktinės multispektrinės indeksų formulės:** įveskite pasirinktinius multispektrinius indeksus į Chloros rastrinius skaičiuoklius, tiek apdorojimui, tiek vaizdų peržiūros sandbox&#x27;ui.
* **Linux ir kraštų kompiuterija:** paleiskite Chloros ant Linux x86\_64 ir ARM64 platformų, įskaitant NVIDIA Jetson, lauko ir kraštų apdorojimui. Žr. [Linux apžvalgą](linux/linux-overview.md).
